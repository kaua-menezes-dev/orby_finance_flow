# Orby Finance Flow

A focused reset package for a personal finance project. **No original reference screenshots are bundled:** copy your own screenshots into `frontend/references/landing/` and `frontend/references/dashboard/`. Videos/GIFs go under `frontend/references/motion/`.

1. Preserve the existing backend repository/code separately; overlay **only** approved docs and references. Do not delete an existing `.git` directory or the backend source.
2. Copy the existing Impeccable skill directory **and** any required configuration/scripts; validate that it works before using it. Existing skills have not been bundled here.
3. Populate references folders with images. Keep descriptive unique names and update `docs/design/references.md` with those actual filenames.
4. Paste extra exact links under `docs/design/motion.md` or `docs/design/references.md`.
5. Start a fresh Claude session with `docs/workflow.md` first task. Ask for a **reference audit only**, no design generation.

Documentation is concise by design; file count is not the primary driver of token usage. Avoid large reads, repetitive generations, and unbounded reviews.
