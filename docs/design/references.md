## Reference rules

- Present image IDs and exact filenames **before** starting a design.
- Map at least two concrete source decisions to each proposed section, but avoid copying a site wholesale.
- References define visual language, **not** app functionality. Do not portray bank sync, investment or financial advice.
- Note inaccessible sources and request original media rather than inferring from prose.
